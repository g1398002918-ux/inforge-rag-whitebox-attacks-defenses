T-SNR 定义：将实际观测到的「问题 → 结构化工具动作 → 每步 Top-3 文档 ID/标题/分数 → 最终答案」送入冻结的目标生成器，对末层 token 表示均值池化并 L2 归一化为 (z)，计算 −10 log10(‖z_clean−z_attack‖²)。它是目标模型空间中的端到端行为信号强度，排除了思维链和金答案；不是声学 SNR，也不同于 e5 输入语义 SNR。∞ 只表示该序列化轨迹的数值表示未产生可分辨差异，不能推出系统的所有内部状态完全相同。
可比性边界：本次为 max-asr profile，明确关闭 e5-SNR 下限并放宽编辑/重叠门控。因此 37.80% 描述的是该设定下的最大攻击能力，不能作为“18 dB 隐蔽攻击”的结果。若要建立严格因果结论，应固定预算和门控，分别消融动作 NLL、梯度定位与候选族。

方法与审计

ASTRA 用冻结目标生成器的白盒梯度定位词级脆弱位置；同时优化干净答案的 NLL、首个工具动作轨迹的 NLL、检索边界代理和多样性。候选均为离散文本变换，包括梯度定位的词内边界、原有锚点回显、疑问词微改写、引号载体等。

成功定义：样本首先必须为 clean-correct；攻击后输出相对金答案的 EM 与 F1 均为 0 才计作成功。未修改模型权重、语料或索引；不向候选或提示中注入金答案。
